# 📚 متجر الكتب — مكتبة سامي

متجر إلكتروني كامل لبيع الكتب (عربي RTL) مع لوحة تحكم كاملة. مبني بـ Node.js + Express بدون قاعدة بيانات خارجية (البيانات تُحفظ في ملفات JSON داخل مجلد `data/`).

## المميزات

**واجهة المتجر**
- صفحة رئيسية احترافية بالكامل قابلة للتحكم من لوحة الأدمن (سلايدر بانرات، بانرات إعلانية، منتجات، أقسام، مميزات، نص وزر).
- صفحات الأقسام، كل الكتب، البحث، العروض، صفحة المنتج (معرض صور، زووم، شريط شراء ثابت على الموبايل).
- صفحة هبوط لكل منتج `/lp/اسم-المنتج` بفورم طلب مباشر (مناسبة لإعلانات فيسبوك/تيك توك).
- سلة جانبية + صفحة سلة + كوبونات خصم + شحن مجاني فوق مبلغ معين.
- صفحة إتمام الطلب: الاسم، الهاتف (إجباري)، هاتف آخر (اختياري)، المحافظة (سعر الشحن تلقائي)، المدينة، العنوان، ملاحظات.
- صفحة الشكر: رقم التحويل وطريقة الدفع والعنوان والوصف (من لوحة التحكم) + رفع صورة الإيصال + زر واتساب برسالة جاهزة فيها كل بيانات العميل والطلب والإجمالي ورابط صورة الإيصال.
- أنيميشن في كل مكان (ظهور العناصر، السلايدر، إضافة للسلة، انتقال الصفحات) مع احترام إعداد "تقليل الحركة".
- متوافق مع كل الأجهزة: لا يوجد خروج عن عرض الشاشة، القائمة الجانبية تقفل تمرير الصفحة ولا تتحرك، الهيدر ثابت بخلفية صلبة.

**لوحة التحكم** — `/admin`
- لوحة معلومات: المبيعات، طلبات اليوم، الطلبات الجديدة، الزوار، رسم بياني 14 يوم، رحلة الشراء، مصادر الزيارات، الأكثر مبيعاً.
- الطلبات: فلترة بالحالة، بحث، تفاصيل الطلب، تغيير الحالة، صورة الإيصال، مراسلة العميل واتساب، طباعة، تنبيه صوتي عند وصول طلب جديد.
- العملاء وخط السير: كل خطوة عملها العميل في الموقع (الصفحات، الكتب اللي شافها، الإضافة للسلة، بدء الطلب، تأكيد الطلب، الضغط على واتساب، رفع الإيصال) + مصدر الزيارة والجهاز.
- الزوار: كل زائر وخط سيره حتى لو لم يشترِ.
- المنتجات: إضافة/تعديل/حذف بالصور (قص وضبط المقاس تلقائياً)، الاسم، السعر، السعر قبل الخصم، الوصف، القسم، المخزون، صفحة الهبوط.
- الأقسام: إضافة/تعديل/ترتيب/إظهار في القائمة (تظهر فوراً للجميع في قائمة الموبايل والكمبيوتر).
- تصميم الصفحة الرئيسية: إضافة وترتيب وإخفاء الأقسام (بانر ← منتجات ← قسم ...).
- أسعار الشحن لكل محافظة + شحن مجاني.
- الدفع وواتساب: رقم التحويل، طريقة الدفع، اسم الحساب، العنوان، الوصف، رقم واتساب.
- الكوبونات، إعدادات المتجر (الاسم، اللوجو، شريط الإعلان، التواصل، السوشيال)، وتغيير بيانات الدخول.

## التشغيل محلياً

```bash
npm install
npm start
```

- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin

أول تشغيل بينشئ بيانات تجريبية (أقسام وكتب وبانرات) تقدر تعدلها أو تحذفها من لوحة التحكم.

## الرفع على سيرفر (Deploy)

المشروع محتاج استضافة تشغل **Node.js** ومعاها **مساحة تخزين دائمة** لمجلد `data/` (فيه الطلبات والصور المرفوعة):

- **VPS** (Hostinger / DigitalOcean / Contabo ...): `npm install && npm start` (ويفضل مع `pm2`).
- **Railway / Render**: اربط الريبو، أمر التشغيل `npm start`، وأضف Volume/Disk وخلي `DATA_DIR` يشاور عليه (مثال: `/data`).
- **Docker**: `docker build -t store . && docker run -p 3000:3000 -v store-data:/app/data store`

> ⚠️ استضافات زي Vercel/Netlify مش مناسبة لأنها مش بتحفظ الملفات المرفوعة.

متغيرات البيئة (كلها اختيارية):

| المتغير | الوصف |
|---|---|
| `PORT` | المنفذ (افتراضي 3000) |
| `DATA_DIR` | مكان حفظ البيانات والصور (افتراضي `./data`) |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | تغيير بيانات دخول الأدمن |
| `NODE_ENV=production` | تفعيل الكاش للصفحة الرئيسية |

## النسخ الاحتياطي

كل البيانات في مجلد `data/` — انسخه بالكامل (db.json + analytics.json + uploads/) للحصول على نسخة احتياطية.
